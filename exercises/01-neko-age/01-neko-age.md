これらの基礎文法を、Python / TypeScript / Go の3言語で横並びに書いて比較する。

## 仕様

猫の年齢（整数、1以上）を1つ受け取り、以下を行う。

### 1. 人間年齢への換算

- 1歳目: 18歳相当
- 2歳目: +9歳（合計27歳）
- 3歳目以降: 1年ごとに+4歳

例:
| 猫の年齢 | 人間年齢 |
| --- | --- |
| 1 | 18 |
| 2 | 27 |
| 3 | 31 |
| 5 | 39 |
| 10 | 59 |

### 2. ライフステージの判定

人間年齢換算後の値をもとに分類する。

- 30歳以下: 「子猫〜若猫」
- 31〜55歳: 「成猫」
- 56歳以上: 「シニア猫」

### 3. 誕生から現在までの挨拶ループ

1歳から入力された年齢まで、1年ずつ増やしながら以下を出力する。

```
1歳(人間年齢18歳): にゃー
2歳(人間年齢27歳): にゃー
3歳(人間年齢31歳): にゃーん
...
```

### 4. 最終的な判定結果を出力

```
この子は現在 <ライフステージ> です。（人間年齢換算: <値>歳）
```

## 入力例

```
5
```

## 出力例

```
1歳(人間年齢18歳): にゃー
2歳(人間年齢27歳): にゃー
3歳(人間年齢31歳): にゃーん
4歳(人間年齢35歳): にゃーん
5歳(人間年齢39歳): にゃーん
この子は現在 成猫 です。（人間年齢換算: 39歳）
```

## 発展（余裕があれば）

- 入力値が0以下の場合はエラーメッセージを出す
- 挨拶のバリエーションを年齢帯によって変える（子猫は「にゃー！」、シニアは「にゃぁ...」など）
